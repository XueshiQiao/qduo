What's New in 26.09.3

  • Put the result back in place — The result panel now has a Replace button, and any action can send its result straight into your document: in place of the selection, after it, or to the clipboard. It only writes where it can confirm the selection is still where you left it; anywhere else the result is copied and the popup tells you why. (#2)
  • Actions beyond AI — Open a URL with the selection filled in (search, dictionary, maps, Obsidian), read it aloud in a voice that matches its language, transform it locally (change case, join PDF line breaks, Simplified ↔ Traditional Chinese, format JSON, strip link tracking, count words and more), or run a Shortcut or shell script on it. A script asks you before its first run.
  • Add from Template — Settings → Actions has ready-made actions to start from, including new AI ones: Summarize, Fix Grammar, Change Tone, Break Down Sentence and Explain Code.
  • More icons, clearer tags — The icon picker has 152 symbols in labelled groups. In the action list, tags now only mark what matters: AI, a missing API key, a script, and where the result goes.

26.09.3 更新内容

  • 结果可以直接放回原处 — 结果面板多了「替换」按钮；每个动作也可以设置让结果直接替换选中的文字、插到它后面，或者放进剪贴板。只有确认选区还在原来位置时才会写入；否则结果会复制到剪贴板，弹窗里告诉你原因。（#2）
  • 不只是 AI 的动作 — 用选中的文字打开网址（搜索、词典、地图、Obsidian），用对应语言的系统声音朗读，本地处理文字（大小写、合并 PDF 断行、繁简转换、格式化 JSON、去掉链接跟踪参数、统计字数等），或者交给快捷指令、Shell 脚本处理。脚本第一次运行前会先问你。
  • 从模板添加 — 「设置 → 动作」里有现成的动作可以直接加，包括新的 AI 动作：总结、语法纠错、改语气、句子解析、解释代码。
  • 更多图标，标签更清楚 — 图标选择器扩充到 152 个，按用途分组。动作列表里的标签只标值得注意的事：AI、缺 API Key、脚本，以及结果去哪。

What's New in 26.09.2

  • First public release — Select text in any app and a small popup appears at the cursor with the actions you set up: copy, search, open a link, or send the selection to a model and read the answer right there.
  • Two popup shapes — A capsule above the selection, or a ring around the cursor. Actions can be grouped; a group opens a second ring beside the first.
  • Your own AI actions — Each action is a prompt of your own, sent to the model you choose, with an optional model per action. Answers stream in as formatted text.
  • Text from anywhere on screen — Press a shortcut, drag a box over anything, and the text inside it comes up in the same popup.
  • One settings file — Everything lives in ~/.config/qduo/config.json, which you can edit by hand. API keys are kept in the Keychain, never in that file.

26.09.2 更新内容

  • 首个公开版本 — 在任何 app 里选中文字，光标旁就弹出你自己设置的动作：复制、搜索、打开链接，或者把选中的文字发给大模型，答案直接显示在原地。
  • 两种弹出样式 — 选区上方的胶囊条，或者围着光标的一圈圆环。动作可以分组，点开一组会在旁边展开第二圈。
  • 自定义 AI 动作 — 每个动作就是你写的一段提示词，发给你选的模型；每个动作也可以单独指定模型。回答边生成边显示，带格式。
  • 屏幕上的文字也能取 — 按快捷键，框选屏幕上任意一块区域，里面的文字会出现在同一个弹窗里。
  • 一个设置文件 — 所有设置都在 ~/.config/qduo/config.json，可以直接手改。API Key 存在钥匙串里，不会写进这个文件。
