没动的地方：下面的「结果」区块（高度自适应、文字大小、朗读高亮）这次不改，窗口里显示成淡色只是为了示意它还在原位。「预览弹窗」按钮在所有方案里都留在外面，不收进高级——它是调样式时最常点的。「恢复默认」只重置这一种样式的细调值，所以跟着细调一起收进高级里。

① 样式怎么选：对比

现在显得怪，主要是两点：三个名字（水玻璃 / 立体玻璃 / 胶囊）光看字想象不出长什么样，只能靠底下一大段说明文字解释；分段按钮在 macOS 上通常用于「视图切换」这类短选项，而这里其实是在选一个外观，系统自己的「外观：浅色 / 深色 / 自动」用的是带缩略图的卡片。

方案样子好处代价 / 风险
A1 现在一行分段按钮 + 底部一段长说明最省地方名字看不出样子，得读说明；就是你说的「怪」
A2 缩略图卡片推荐三张小图并排，选中的描蓝边，下面一行说明只讲选中的那个一眼看出区别；和 macOS 系统设置里「外观」的选法一致；底部那段长说明可以删掉要画三张缩略图（可以用真实弹窗截图）；纵向多占约 110pt
A3 单选列表三行，每行：圆点 + 小图 + 名字 + 一句说明说明直接挨着选项，信息最完整最占高度（三行）；小图偏小，看细节不如 A2
