动作编辑器：图标、分组、URL 开关的方案

三件事各出几版，都是示意图，图标用的是真的 SF Symbol。搜索小窗口里的输入框可以真的打字试（示意图里只放了 60 个图标，真正做出来是这台 Mac 上全部的 SF Symbol）。

一、图标区

三版都按你说的分三块：推荐图标、搜索 SF Symbols（点了之后弹出小窗口）、自定义图片。区别是后两块的入口放在哪里。搜索小窗口三版共用同一个设计。

三版共用。要求写在这里，不占编辑器的地方。选好之后小窗口关掉，图标区显示这张图，旁边出现「移除」。

其他尺寸会缩放成 256×256；图片按原样显示，不跟随主题变色。

三版共用的规则

  • 搜索小窗口：每打一个字，下面的结果立刻更新；名字以输入内容开头的排在前面，其次是名字里包含它的。点一个图标，底部显示它的名字，点「使用」后关闭。
  • 选了搜索到的图标或自定义图片之后，推荐图标里没有哪个是选中状态，所以要有一个地方显示「当前用的是什么」：A 版我会在「更多图标」那一行的左边显示当前图标和名字，B 版在标题旁边，C 版是第一个格子。
  • 文案统一叫「自定义图片」，不再用「用自己的图片」。

二、分组也能执行动作：设置里怎么给它安排动作

现在的做法是在分组的编辑器里加了一项「点击分组时」和一个选项「只展开，不执行动作」，这是两个新说法。下面三版都不加新说法，尽量让「给分组安排动作」和「新建一个动作」是同一套流程。

A · 分组就是一种「类型」

分组的编辑器和动作的编辑器完全一样，还是那个「类型」。类型列表里第一项是「分组」，选它就是以前那种只展开的分组；选别的类型，它就既能展开、点击又能执行。「新建分组」等于「新建动作」并把类型预先选成「分组」。

B · 分组里的第一格

编辑器不动。在动作列表里，每个分组下面第一行是一个固定的格子，放「分组自己的动作」。空的时候格子里就是列表底部那两个按钮：新建动作、从模板添加，走的是完全一样的流程。也可以把一个现成的动作拖进这个格子。

C · 把动作拖进动作里

不需要「给分组安排动作」这一步：先像平常一样建好一个动作，再把别的动作拖到它身上，它就成了分组，点击时还是执行它自己。「新建分组」保留，建出来的是不执行任何动作的空分组。编辑器和列表都不加东西。

三、URL 开关放在编辑器最下面

不管这个动作是什么类型、上面有多少设置，这个开关都固定在整页的最后。关着的时候只占一行。

任何 app、任何网页上的链接都能打开这样的 URL，所以默认关闭，每个动作单独打开。

说明

  • 顺序：名称和类型 → 图标 → 这种类型自己的设置（提示词、模型、网址、脚本……）→ URL 开关永远最后。
  • 开关关着时，下面的「动作名」和示例 URL 两行不显示，整块只有一行。
  • 开关的文字我写的是「允许其他 app 通过 URL 运行此动作」，你可以直接改。
  • 动作名存在 ~/.config/qduo/config.json 里，就在这个动作自己的那一段："urlName": "translate"。删掉这一行就等于关掉开关。
