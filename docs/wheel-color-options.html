悬停时图标和文字用什么颜色

现在（v2，已提交）：悬停那一格的图标和文字变成系统强调色（tint color），组开着时淡一些。下面是几种更有性格的配色思路，每种都画了三张图：悬停普通动作、悬停一个组、进到二级菜单。尺寸 1:1，菜单是 B′。顶部可以切深色背景、放大。

对比

颜色从哪来颜色有没有含义跟系统强调色走吗工作量
现状系统强调色没有是（换了粉色也跟着粉）—
A 品牌渐变QDuo 图标的蓝 → 青"这是 QDuo"否，永远是品牌色小：一个渐变替换一个颜色
B 色轮这一格在圆环上的角度没有，纯装饰否小：按角度算颜色
C 按类别动作类型（AI / 查询 / 系统）有：一眼看出哪些是 AI否中：动作类型已有，定一套三色
D 每个动作自带用户在设置里挑用户自己定否大：配置文件 + 设置页 + 默认调色板

我的推荐：A 品牌渐变

  • 最有辨识度：蓝 → 青就是 QDuo 图标的颜色，放进宣传视频里，悬停的那一下就在强化品牌。
  • 和 Liquid Glass 的冷色调天然搭配，浅色、深色背景下都清楚；也不会因为用户把系统强调色换成粉色、黄色而变得不协调。
  • 改动小：只把"悬停颜色"从一个纯色换成一个渐变，组外沿的刻度也用同一渐变的起始色，全局统一。
  • 如果想让颜色带信息量，C 按类别是第二选择——视频里观众能看出"这几个是 AI"。B 和 D 更像玩具或个性化选项，适合以后做成设置里的一个开关。

说明：玻璃效果用浏览器的背景模糊模拟，真实的 Liquid Glass 还会有折射，会更通透一些；图标是按 SF Symbols 手画的近似版本。几何位置（文字、圆点、刻度、弧线的半径和角度）和 app 代码一致。
