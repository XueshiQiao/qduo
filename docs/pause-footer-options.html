左下角：不用 Switch 还能怎么放

下面的侧边栏都是按真实尺寸画的（宽 212pt）。每个方案左边是「运行中」，右边是「已暂停」。「hover」表示鼠标移上去的样子。

A · 整行是一个按钮

平时只是一行状态文字；鼠标移上去整行变成可点的样子，并出现「暂停」。跟 Finder、邮件侧边栏底部那种状态行一个路数，安静。缺点：不 hover 的时候看不出它能点。

B · 状态文字 + 暂停/播放小图标

右边一个无边框的小图标按钮：运行中显示 ⏸，暂停后显示 ▶。像播放器，含义一看就懂，占地最小。缺点：图标按钮要靠 tooltip 解释，比文字弱一点。

C · 平时很安静，暂停了才醒目推荐

两种状态本来就不对等：「运行中」是正常情况，不用喊；「已暂停」是你可能忘了的异常情况，得让人一眼看到。所以运行中只是一行小字加一个「暂停」文字按钮；暂停后变成一张橙色提示卡，写清楚后果，带一个「恢复」按钮。

D · 挪到左上角 Logo 旁边，做成状态标签

不放左下角了：版本号下面（或旁边）放一个小标签「● 运行中」，点开是个小菜单（暂停 / 恢复）。状态和 App 名字在一起，很自然。缺点：要点两下；左下角原来的缺权限警告还得留着，状态就分在上下两处。
