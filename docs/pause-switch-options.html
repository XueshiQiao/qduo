「暂停 QDuo」开关放哪儿

暂停 = 选中文字后不再弹出圆环 / 胶囊条。菜单栏的入口是定的；下面是主窗口里三个候选位置（A / B / C），以及菜单栏菜单和菜单栏图标在「运行中 / 已暂停」两种状态下的样子。橙色描边 = 新加的东西。

一、主窗口入口：三个候选

A · 右上角工具栏按钮

每一页都看得到。但工具栏右上角在 macOS 上一般放「跟当前页面有关」的操作；一个全局开关放这里，和页面内容挨着，容易被误以为只管这一页。

二、菜单栏入口

注意：现在 QDuo 的菜单栏图标左键、右键点都是直接弹出同一个菜单（代码里特意这么做的，因为没有 Dock 图标，菜单是唯一入口）。所以「右键才有暂停项」做不到区分——建议暂停项就放在这个菜单里，左右键都能看到。

三、菜单栏图标：暂停时长什么样

现在图标「变灰」已经被用来表示「缺辅助功能权限」。暂停如果也用变灰，两种情况就分不出来了。

状态方案 1：暂停也变灰方案 2：图标里加暂停符号（推荐）
运行中
已暂停
缺权限 ← 和暂停一模一样
要改掉一条旧的设计判断。代码里（PopBarController.startIfPermitted 和 StatusFooter 的注释）明确写着「故意不做开关」，理由是：开关只是更慢的退出，而且 app 会待在菜单栏里什么都不干、看起来却和在干活一样。这次加开关，第二个担心要靠「暂停时图标和侧边栏都明显显示已暂停」来解决——所以上面的图标方案 2 和侧边栏状态栏不是装饰，是这个功能成立的前提。
